# Sutra for VS Code

1. Download `sutra-ide-0.1.0.vsix` from GitHub Releases.
2. VS Code: Extensions → … → Install from VSIX.
3. Open a folder. Command Palette: **Sutra: Write specs**.
4. Shell commands prompt Allow / Always allow this workspace / Deny, then run in `cmd.exe` (Windows) or zsh (macOS).
